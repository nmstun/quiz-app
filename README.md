# 咲登クイズ

音声入力で答える、子ども向けの算数・雑学クイズアプリ。ビルド不要の静的Webアプリで、iPhoneのSafari(およびホーム画面に追加したPWA)での利用を想定しています。

🔗 **遊ぶ**: https://quiz-app-nanastun.vercel.app

## 特徴

- **10カテゴリ**: 算数 / 漢字 / 都道府県 / 地図記号 / なぞなぞ / モビルスーツ / からぴち / スマブラ / 究極の選択(正解なしパーティークイズ) / 達人(ランダムミックス)
- **音声入力で回答**: Web Speech APIを使用。非対応環境ではテキスト入力に自動フォールバック
- **学年別の出題範囲**: 算数・漢字はそれぞれ学年帯を選んで難易度調整が可能
- **ふたりで交互モード**: 1問ずつ手番を回して対戦し、勝敗を表示
- **復習機能**: 間違えた問題だけをもう一度解き直せる
- **成績の記録**: コースごとのベストスコアと直近10回の成績履歴をlocalStorageに保存し、棒グラフで振り返り可能
- **PWA対応**: ホーム画面に追加すればオフラインでも遊べる
- **ライト/ダークテーマ**: 端末設定に自動追従

## 遊び方

1. カテゴリ・(必要なら)学年・人数・問題数コースを選ぶ
2. 音声またはテキストで回答
3. 終了後に正解数・所要時間・問題ごとの結果を確認

## 開発

ビルド不要の静的サイトです。

```bash
git clone https://github.com/nmstun/quiz-app.git
cd quiz-app
python3 -m http.server
```

ブラウザで `http://localhost:8000` を開くだけで動作します。

### テスト

依存パッケージなしの回帰テストを同梱しています。

```bash
node test.js
```

## データの出典・著作権への配慮

- 漢字データ: [KANJIDIC2](https://www.edrdg.org/wiki/index.php/KANJIDIC_Project)(CC BY-SA)
- 都道府県の緯度経度データ: [four4to6/pref_lat_lon](https://github.com/four4to6/pref_lat_lon)(MIT License)
- 地図記号: 国土地理院の公式画像を参考に独自に描き起こしたSVG(公式画像そのものの複製ではない)
- モビルスーツ・スマブラ・からぴちの各クイズ: 画像やキャラクターデザインは使用せず、テキストの事実情報のみを扱う
